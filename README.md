# Task 03 — Automated Bioinformatics Pipeline

An end-to-end, reproducible Python pipeline that retrieves a nucleotide sequence from NCBI, runs a remote BLASTN search, and creates an annotation table. The workflow is based on the ACTB sequence used in Task 02, but the three analysis stages are now chained by one main script.

## What the pipeline does

1. **Sequence retrieval:** downloads the configured RefSeq accession from NCBI Nucleotide and saves the FASTA file.
2. **Sequence similarity search:** submits the FASTA sequence to NCBI BLASTN and saves the raw XML response as an intermediate file.
3. **Annotation:** parses the retained BLAST XML and writes a CSV table containing subject accession/title, alignment length, percent identity, approximate query coverage, E-value, and bit score.
4. **Run record:** saves the analysis settings, timestamp, and output locations in a JSON metadata file.

Intermediate FASTA and BLAST XML files are retained so that each stage can be inspected. No BLAST result values are fabricated or pre-filled.

## Requirements

- Python 3.9 or newer
- Internet connection (NCBI Entrez and BLAST are remote services)
- A valid email address for NCBI Entrez identification

## Run from a clean checkout

Clone or download this repository, then open Terminal in the project folder.

### 1. Create and activate a virtual environment (recommended)

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Set your NCBI email address

macOS/Linux:

```bash
export NCBI_EMAIL="your.email@example.com"
```

Use your own email address. Do not put personal email addresses or credentials in the source code.

### 4. Run the complete pipeline with one command

```bash
python pipeline.py
```

The script runs all stages in order. It creates the required output directories automatically and writes progress to the terminal and `results/pipeline.log`. A non-zero exit status is returned if a stage fails.

## Parameters

All analysis settings and project paths are grouped at the top of `pipeline.py`:

| Parameter | Default |
|---|---|
| `ACCESSION` | `NM_001101.5` |
| `BLAST_PROGRAM` | `blastn` |
| `BLAST_DATABASE` | `nt` |
| `EXPECT_THRESHOLD` | `10.0` |
| `MAX_HITS` | `10` |
| `MEGABLAST` | `True` |

Change these values in that section to configure a different run. The output paths are also defined together there and are anchored to the script location, so running from another working directory does not break relative paths.

## Outputs

| File | Purpose |
|---|---|
| `data/query_sequence.fasta` | Retrieved query sequence |
| `results/intermediate/blast_results.xml` | Raw BLAST XML intermediate |
| `results/final/annotation_table.csv` | Parsed annotation results |
| `results/run_metadata.json` | Timestamp, parameters, and output record |
| `results/pipeline.log` | Execution log |

NCBI remote BLAST requests can take several minutes or be temporarily queued. Avoid repeatedly submitting the same search. The annotation table is generated from the XML returned by NCBI.

## Interpretation note

Percent identity describes identical aligned positions. Query coverage here is an approximate one-HSP calculation (alignment length divided by query length, capped at 100%). E-value and bit score describe alignment significance. Sequence similarity alone does not establish biological function; inspect the matched NCBI records before making functional claims.
